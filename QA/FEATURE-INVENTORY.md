# Pactra Feature Inventory

Audit date: 2026-11-07 (Africa/Lagos)  
PRD baseline: `Pactra-PRD-Judge-Ready.md`  
Audited production URL: `https://pactra-nine.vercel.app`  
Audited release: `0e3e905` (backend and frontend)  

Status vocabulary in this document is implementation-oriented: **Implemented**, **Partial**, **Disabled**, **Broken**, or **Missing**. Test outcomes are recorded separately in `TEST-MATRIX.md`.

## Summary

| Implementation status | Count |
|---|---:|
| Implemented | 50 |
| Partial | 9 |
| Disabled/unconfigured | 4 |
| Broken | 0 |

| **Total features discovered** | **64** |

The single wholly missing PRD feature is password reveal. Five other PRD expectations exist only partially: the guided scenario set, payment likely-decision preview, approval-card context, lifecycle actor/payload display, and ledger account/counter-account display. Gemini and PayPal execution are implemented but disabled in production, not absent.
